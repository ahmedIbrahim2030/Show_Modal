# Modal Window Project

This project is a simple front-end exercise built with vanilla JavaScript and DOM event handling. It demonstrates a reusable modal popup that opens from multiple buttons and closes using several interactions.

## Features

- Three buttons to open the modal
- Dark overlay behind the modal
- Close button inside the modal
- Click outside the modal to close it
- Press the Escape key to close the modal
- Clean styling with a modern card-like modal design

## Project Files

- `index.html` – page structure and modal markup
- `style.css` – layout, modal styling, and hidden/visible states
- `script.js` – JavaScript logic for opening and closing the modal

## How to Run

1. Open the project folder in your browser.
2. Open `index.html` directly in a browser or serve it with a local web server.
3. Click any "Show modal" button to open the popup.
4. Close it by clicking the close icon, clicking the overlay, or pressing `Escape`.

## Example Use Case

This project is a great example of:

- DOM selection with `querySelector` and `querySelectorAll`
- Adding event listeners
- Toggling CSS classes for show/hide behavior
- Handling keyboard events

## Notes

This project uses no external libraries or build tools, so it is easy to run and modify for learning purposes.
